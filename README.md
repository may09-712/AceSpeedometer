AceSpeedometer

A clean and lightweight speedometer mod for Gorilla Tag that displays your movement speed in real time while you play.

Features
Real-time speed tracking
Easy to install
Optimized for performance
Works in modded lobbies

Installation

Install BepInEx
Download the latest release of AceSpeedometer
Drag the .dll file into your BepInEx/plugins folder
Launch the game

Requirements
Gorilla Tag
BepInEx
PCVR-compatible setup

Why Use AceSpeedometer?

AceSpeedometer helps players:

Track movement speed
Improve movement mechanics
Practice advanced routes
Compare movement performance with friends

Perfect for competitive and casual players alike.
